# Sample audio

วางไฟล์ `.wav` หรือ `.flac` สำหรับทดลองไว้ในโฟลเดอร์นี้

เงื่อนไขที่แนะนำ:

- เป็นเสียงพูด ไม่ใช่เพลง
- ยาวอย่างน้อย 4 วินาที
- ไฟล์ mono หรือ stereo ก็ได้ ระบบจะรวมเป็น mono
- sample rate ใดก็ได้ ระบบจะ resample เป็น 16 kHz

ไฟล์เสียงในโฟลเดอร์นี้ถูก `.gitignore` เพื่อไม่ให้ข้อมูลเสียงส่วนบุคคลถูก commit โดยไม่ตั้งใจ
