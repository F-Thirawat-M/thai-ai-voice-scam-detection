# เสียงทดลอง inference

วาง WAV/FLAC ส่วนตัวเพื่อทดสอบคำสั่ง infer ได้ โฟลเดอร์นี้ไม่ใช่ Train/Dev/Test และไฟล์ทุกชนิดนอกจาก README นี้ไม่เข้า Git

- ระบบปัจจุบันรวม channel เป็น mono และ resample เป็น 16 kHz
- ค่าเริ่มต้นใช้ 64,600 samples: ยาวกว่านั้นใช้ช่วงแรก สั้นกว่านั้นวนซ้ำ
- ไม่จำเป็นต้องมีความยาวขั้นต่ำ 4 วินาที แต่เสียงสั้นมากอาจไม่เหมาะกับการประเมิน
- สร้าง `smoke_tone.wav` ใหม่ด้วย `scripts/create_smoke_audio.py`; เป็นสัญญาณจำลอง ไม่ใช่เสียงพูดหรือ corpus วิจัย

ไฟล์ทดลองเก่าถูกล้างระหว่างปรับโครงสร้าง สามารถเพิ่มไฟล์ใหม่ที่มีสิทธิ์ใช้ได้ ข้อมูลหลักให้อยู่ตาม [data/README.md](../README.md)
