# รายงานของการทดลองใหม่

เก็บ literature matrix, theory notes, audit summary และผลวิจัยที่ตรวจแล้วและเผยแพร่ได้ ยังไม่มีผล main experiment/Final Test ในโฟลเดอร์นี้ ผล pilot อ่านจาก `experiments/pilot/docs/`

ตารางระดับคลิป/ผู้พูดหรือ outputs ที่มีข้อมูลส่วนตัวอยู่ใน `experiments/pilot/notebooks/outputs/` และ `results/pilot/` ที่ไม่เข้า Git ไม่คัดลอกมาในรายงานโดยไม่ตรวจสิทธิ์ ส่วน `results/research/` ยังเป็นเส้นทางเสนอสำหรับงานจริง
