# ปรับโครงสร้างและล้างแผนเก่า — 3 ตุลาคม 2026

ผู้ใช้อนุญาตให้ปรับโครงสร้างตาม Common Voice + TTS และลบไฟล์/โฟลเดอร์ที่เลิกใช้แล้ว ไม่ได้สร้าง archive สำเนาข้อมูลเก่าไว้กินพื้นที่ต่อ

## ลบแล้ว

- `data/raw/sea_spoof_hf/`: Parquet และไฟล์ดาวน์โหลดชุดเก่า
- `data/raw/sea_spoof_metadata/`, `data/raw/typhoon_thai_dialect_isan/`: metadata ที่โหลดไว้
- `data/processed/sea_spoof_th/`: เสียงที่สกัดไว้ 19,807 ไฟล์
- `data/exploration/sea_spoof/`, `data/exploration/typhoon_thai_dialect_isan/`: notebook/helper/README และ outputs ทั้งหมด
- `data/manifests/thai_dev.csv`, `thai_test.csv` และโฟลเดอร์ manifests กลางเดิม
- สคริปต์ `audit_dataset_metadata.py`, `extract_thai_parquet.py`, `run_sea_spoof_eda.py`, `run_sea_spoof_metadata_eda.py`, `run_typhoon_isan_eda.py` และ tests เฉพาะสี่ไฟล์ที่ผูกกับ pipeline เก่า
- `docs/RESEARCH_PLAN_TH.md`: แผน SEA-Spoof/ชุดเสริมเดิมที่ขัดกับทิศทางใหม่
- ผล structure/smoke/audit เก่าใน `results/` และ temporary/archive ของงานเก่า 15 เป้าหมายที่ตรวจแล้วใน `tmp/`
- เสียงทดลอง `data/sample/check01.wav`, `check02.wav` และ smoke เก่า; สร้าง `smoke_tone.wav` ใหม่เพื่อทดสอบระบบปัจจุบัน
- `checkpoints/rawnet2/pre_trained_DF_RawNet2.zip`: archive ที่แตกแล้ว ลบหลังยืนยัน SHA-256 ของ `.pth` ที่เก็บไว้ตรงกับ checksum ในตัวติดตั้ง
- Python cache เก่าของ scripts/tests; การรัน tests ใหม่อาจสร้าง cache ใหม่ตามปกติ

ขนาดไฟล์ข้อมูล/output/cache/temporary/archive ที่ลบซึ่งตรวจนับได้รวม **19,490,445,345 bytes ≈ 18.15 GiB (19.49 GB)** ไม่รวมขนาด source ที่ลบผ่าน patch เป็นผลรวม logical file sizes ไม่ใช่การวัดพื้นที่ disk ว่างจริงหลังหักไฟล์ใหม่หรือ compression

## ปรับและเตรียมใหม่

- เขียน root README และคู่มือผู้เริ่มต้นใหม่ ให้เริ่มจาก Common Voice/TTS โดยไม่ชี้ไป pipeline ที่ลบ
- ปรับ workflow หลักให้สถานะ/โครงสร้าง/คำสั่งส่งต่อสอดคล้องกับ cleanup ไม่ยังบอกให้เก็บข้อมูลที่ถูกลบแล้ว
- เพิ่มคู่มือโครงสร้าง, docs index, decision log และพื้นที่รายงาน
- เตรียม `configs/cvtts/`, `src/thai_spoof/cvtts/`, `tests/cvtts/`, `data/exploration/common_voice/` เป็น scaffold ที่ระบุชัดว่ายังไม่มี implementation
- เตรียม local data roots `data/raw/common_voice/`, `data/raw/noise/`, `data/processed/cvtts/` ยังไม่มี dataset ใหม่
- ย้ายตัวอย่าง manifest เป็น placeholder ที่ `examples/inference_manifest.csv`; manifest จริงของแผนใหม่อยู่ใต้ `data/processed/cvtts/<version>/manifests/`
- เพิ่ม ignore rules สำหรับ `.venv-*`, `.env` และ sample files ทุกชนิด; raw/processed/results/checkpoints และ EDA outputs ยังไม่เข้า Git

## เก็บไว้เพราะยังใช้ต่อ

source/adapters/config/license ของ AASIST และ RawNet2, `external/aasist/`, checkpoint `.pth` ทั้งสอง, `.venv`, CLI/metrics, environment/setup/smoke scripts และ baseline audio/metrics tests

ไม่ได้อัปเกรด dependency เปลี่ยน architecture/weights ดาวน์โหลดข้อมูลใหม่ เริ่ม fine-tune หรือแตะ cache/dataset ที่อยู่นอก project นี้

## การกู้คืน

- Source/notebook/docs/tests ที่เคย commit แล้ว: ดูหรือกู้เฉพาะไฟล์จาก Git history ได้ การลบรอบนี้ยังไม่ commit
- Dataset/audio/metadata/outputs ที่ ignore: **กู้จาก Git ไม่ได้** และลบถาวรจาก project ไม่ได้ย้ายเข้า Recycle Bin ต้องดาวน์โหลดหรือสร้างใหม่ตามสิทธิ์ของต้นทาง หรือใช้ backup ที่ผู้ใช้มีเอง
- `.zip` ของ RawNet2 ดาวน์โหลดใหม่ได้; `.pth` ที่ใช้งานยังเก็บอยู่
- อย่ากู้ข้อมูลเก่ากลับมาเพียงเพราะพบชื่อในประวัติ เริ่มงานใหม่ตาม workflow ปัจจุบัน
